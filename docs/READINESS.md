# 数学与独立验收

只补当前任务需要的数学，不另开一门完整课程。前置检查使用当周前五天的学习预算；已会则直接通过，不会则减少选做、用缓冲或顺延。

| 检查 | 进入阶段 | 最小任务 | 通过证据 |
|---|---|---|---|
| M1 | W03 kNN | 手算两向量的 L1/L2 距离、三个数的均值与方差；说明 X 为 N×D、W 为 D×C 时 XW 的形状 | 手算结果与 NumPy 核对 |
| M2 | W04 Softmax | 求 x² 和 log(x) 的导数；求 x²+xy 对 x、y 的偏导；用链式法则求 log(1+exp(x)) 的导数 | 推导并用有限差分核对 |
| M3 | W05 反向传播 | 对 affine→ReLU→affine 的两层网络逐层标出形状；解释上游梯度如何通过链式法则传递 | 小输入的解析梯度与数值梯度核对；避开 ReLU 在零点的不可导位置 |
| M4 | W11 Attention | 计算 QKᵀ 和 attention×V 的形状；解释 softmax 按行归一化、缩放因子的作用 | 手算小矩阵并与实现核对 |

课程前置要求见 [CS231n](https://cs231n.stanford.edu/)；Python/NumPy 基础见 [官方教程](https://cs231n.github.io/python-numpy-tutorial/)。按任务查讲义和笔记，不必为补缺同时追多门课。

## 怎样算通过

1. 可查 API 文档，自己写核心代码；验收时不让 AI 生成核心实现。
2. 改输入维度、序列长度或一个配置后，能解释并修正实现。
3. 至少记录一个错误、定位过程或失败实验。AI 辅助排错后，自己重新解释和重做。
4. 证据写进对应周文件和复盘；统计完成率不代替能力判断。

## 未通过时

- 先用周六缓冲补最关键卡点，周日记录真实状态。
- W05 前向/反向仍不会时，暂停后续新内容，下一周先重练；压缩选做或延长日历，不叠加两周任务。
- 其它阶段同样优先保留基础能力、削减扩展项目。记录“当前实际学习 Wxx”，日历显示不代表应强行进入该周。
- 延期后日志仍按真实日期记录。进度面板的周时长按原日历归属；跨周补课在日志注明实际学习周，不能据日历时长判断能力。
